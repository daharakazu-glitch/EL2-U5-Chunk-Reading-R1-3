# EL2-U5-Chunk-Reading-R1-3

E.C. II Unit 5: What can we learn from traveling?
Reading 1 Part 3

チャンクリーディング & 暗誦・リスニング・発話練習Webアプリケーション

## 機能
- **チャンクリーディング & 穴埋め**: ヒント付きの空所（( ) や頭文字ヒント）をクリックして正解を表示／非表示
- **音声録音 & 再生**: マイク録音による発音・音読練習
- **進捗表示 (Progress)**: 開示済み空所数のカウント表示
- **解答順次表示 (Next Answer)** / **全表示 (Show All)**
- **音声読み上げ (TTS)**: チャンクごとの連続再生（行ハイライト連動）および行ごとの個別音声再生
- **日本語訳 表示切替 (ON/OFF)**
- **リセット機能**
